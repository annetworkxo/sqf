# Shubhkiran Quality Forum — static website

Plain HTML, CSS, and JavaScript. No build step. This is the folder to put on GitHub.

## Put it on GitHub Pages

1. Create a new repository on GitHub (public).
2. Upload everything inside this folder to the repository root. Include `index.html`, `css`, `js`, and `assets`. Do not upload only the zip.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Branch: `main`. Folder: **/ (root)**. Save.
6. Wait a minute. The site will be at `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`.

## Files

- `index.html` and the other `.html` pages are the site
- `css/styles.css` is the design
- `js/site.js` handles the menu, service search, photo gallery, and the enquiry form
- `assets/` holds the logo, photos, client logos, and the company profile PDF

The enquiry form does not store messages. It opens WhatsApp or the visitor’s email app.
